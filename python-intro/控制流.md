# 控制流

控制流是命令式编程（imperative programming）中的重要概念，它决定程序以什么顺序执行指令。本节主要介绍 Python 的分支和循环。

## 分支控制结构

分支结构根据条件选择要执行的代码。

### `if`、`elif` 和 `else`

- 单分支使用 `if`。
- 双分支使用 `if` 和 `else`。
- 多分支可以在 `if` 后接一个或多个 `elif`，最后的 `else` 可省略。条件按顺序检查，执行第一个条件为真的分支。

### 三元表达式

如果只需要根据一个简单的条件在两个值之间选择，可以使用条件表达式，也叫三元表达式。

```python
age = 20
age_group = "成年" if age >= 18 else "未成年"
print(age_group)
```

### 模式匹配（pattern matching）

在学习了 Haskell 之后，我认识到了模式匹配的重要性。Python 也支持结构化模式匹配，从 Python 3.10 起可以使用 `match` 和 `case` 这两个软关键字。

```python
point = (0, 5)
match point:
    case (0, 0):
        print("原点")
    case (0, y):
        print(f"在 y 轴上,y={y}")
    case (x, 0):
        print(f"在 x 轴上,x={x}")
    case (x, y):
        print(f"普通点 ({x}, {y})")
```

上面的例子按顺序尝试各个 `case`，执行第一个匹配成功的分支。`(0, 5)` 匹配 `case (0, y)`，把 `y` 绑定为 `5`。

在 Haskell 中，模式可以匹配由数据构造器（data constructor）创建的值。例如，`Just` 是数据构造器，`Maybe` 是类型构造器（type constructor）。上面的 Python 示例使用了序列模式。Python 也支持类模式，可以检查对象是否是指定类的实例并提取属性。类模式等系统学习完面向对象编程（OOP）之后再展开。

## 循环控制结构

循环控制结构用于重复执行一段代码。

### `for` 循环

Python 的 `for` 循环从可迭代对象中依次取出元素。下面是几种常用写法。

```python
# range(5) 依次提供 0 到 4。
for i in range(5):
    print(i)

# enumerate() 同时提供编号和元素，默认从 0 开始编号。
names = ["小明", "小红", "小刚"]
for i, name in enumerate(names):
    print(i, name)

# zip() 按位置配对，默认在最短的可迭代对象耗尽时结束。
names = ["小明", "小红"]
scores = [90, 85]
for name, score in zip(names, scores):
    print(name, score)
```

上面都有了一些函数式编程的影子

### `while` 循环

`while` 在每轮开始前检查条件，条件为真时执行循环体，条件为假时退出。如果条件一开始就为假，循环体一次也不会执行。

## 推导式

Python 的列表推导式和 Haskell 的列表推导式（list comprehension）有些相似。Python 还支持字典推导式、集合推导式和生成器表达式。生成器表达式会在迭代时逐个产生值。

```python
squares = [x**2 for x in range(5)]
evens = [x for x in range(10) if x % 2 == 0]  # for 后面的 if 用于筛选元素
d = {x: x**2 for x in range(5)}
s = {x % 3 for x in range(10)}
gen = (x**2 for x in range(5))
```
