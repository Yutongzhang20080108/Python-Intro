# 高级数据结构

本章从可变性和迭代方式两个角度认识 Python 对象，再介绍标准库 `collections` 中的三种容器。

## 可变与不可变（mutable and immutable）

可变对象可以在创建后原地修改。不可变对象在创建后保持原有的值，变量可以通过重新赋值指向另一个对象。

- 常见的可变类型有 `list`、`dict` 和 `set`。
- 常见的不可变类型有 `int`、`float`、`bool`、`str`、`tuple` 和 `bytes`。

把一个变量赋给另一个变量时，两个名字会指向同一个对象。调用 `numbers.append(3)` 会原地修改列表，因此 `same_list` 也能看到新增的元素。字符串拼接得到一个新字符串，赋值后可以用 `word` 读出拼接结果，用 `original` 读出原来的字符串。

```python
numbers = [1, 2]
same_list = numbers
numbers.append(3)
print(same_list)  # [1, 2, 3]

word = "py"
original = word
word = word + "thon"
print(word)  # python
print(original)  # py
```

元组各个位置引用的对象固定。如果元组包含列表，仍然可以调用列表的 `append()` 修改其中的内容。字典的键和集合的元素必须可哈希，元组只有在其元素都可哈希时才满足这个要求。例如，`(3, 4)` 可以作为字典的键，对包含列表的元组 `([3, 4],)` 调用 `hash()` 会抛出 `TypeError`。

## 可迭代对象与迭代器（iterable and iterator）

`for` 循环和 `list()` 都可以接收可迭代对象。常见的例子有列表、元组、字符串、字典、集合和 `range` 对象。

```text
可迭代对象 --iter()--> 迭代器 --next()--> 下一个元素
```

- **可迭代对象（iterable）**可以用 `iter(obj)` 取得迭代器。通常由 `obj.__iter__()` 返回迭代器。对于仅实现序列协议的对象，迭代器从索引 `0` 开始调用 `__getitem__()`，遇到 `IndexError` 时结束。
- **迭代器（iterator）**的 `__next__()` 每次返回下一个元素，耗尽时抛出 `StopIteration`。`__iter__()` 返回迭代器自身，因此迭代器也是可迭代对象。`for` 循环会自动处理 `StopIteration` 并结束。

迭代器会记住读到的位置。下面先用 `next()` 取出一个元素，再用 `list()` 收集剩余元素。

```python
numbers = [10, 20, 30]
iterator = iter(numbers)

print(next(iterator))  # 10
print(list(iterator))  # [20, 30]
print(list(iterator))  # []
print(list(numbers))  # [10, 20, 30]
```

对列表调用 `iter(numbers)` 会得到一个从头开始的新迭代器。生成器表达式 `(x**2 for x in range(3))` 的结果本身就是迭代器，消耗完后需要重新创建才能再次取值。

## `defaultdict`

`defaultdict` 是 `dict` 的子类，适合按键分组或累计数值。创建时可以传入 `list` 等可调用对象作为默认工厂。设置工厂后，通过 `d[key]` 访问缺失的键会无参数调用工厂，把得到的值存到该键下并返回。`defaultdict(list)` 会为每个首次访问的缺失键创建独立的空列表。

```python
from collections import defaultdict

students = [("一班", "小明"), ("二班", "小红"), ("一班", "小刚")]
by_class = defaultdict(list)

for class_name, name in students:
    by_class[class_name].append(name)

print(dict(by_class))  # {'一班': ['小明', '小刚'], '二班': ['小红']}
print(by_class.get("三班"))  # None
print("三班" in by_class)  # False
print(by_class["三班"])  # []
print("三班" in by_class)  # True
```

`get()` 沿用普通字典的行为，遇到缺失的键时返回 `None` 或传入的默认值。用 `defaultdict(int)` 可以让新键从 `0` 开始累加。

## `Counter`

`Counter` 是用于计数的字典子类，以可哈希的元素为键，出现次数为值。可以直接传入字符串、列表等可迭代对象。`counts[key]` 在键缺失时返回 `0`。`most_common(n)` 按次数从高到低返回前 `n` 项，每项都是 `(元素, 次数)`。省略 `n` 可以取得所有项。

```python
from collections import Counter

counts = Counter(["猫", "狗", "猫", "兔子", "猫", "狗"])

print(counts["猫"])  # 3
print(counts["鸟"])  # 0
print("鸟" in counts)  # False
print(counts.most_common(2))  # [('猫', 3), ('狗', 2)]

counts.update(["狗", "狗"])
print(counts["狗"])  # 4
```

`update()` 把新一批数据的次数累加到已有计数上，可以用它分批统计。

## `deque`

`deque` 是双端队列（double-ended queue）。`append()` 和 `pop()` 在右端添加和取出元素，`appendleft()` 和 `popleft()` 在左端完成相同的操作。两端追加或弹出一个元素的时间复杂度都是 `O(1)`。对空队列调用 `pop()` 或 `popleft()` 会抛出 `IndexError`。

用 `append()` 从右端入队、用 `popleft()` 从左端取出，就能按加入的顺序处理任务。这种顺序叫作先进先出（FIFO）。

```python
from collections import deque

tasks = deque(["下载", "解压"])
tasks.append("导入")

print(tasks.popleft())  # 下载
print(list(tasks))  # ['解压', '导入']
```

可以用 `maxlen` 限制队列长度。下面的队列最多保留三条记录，装满后每次从右端追加都会自动移除左端最早的记录。

```python
from collections import deque

recent = deque(maxlen=3)
for event in ["启动", "读取", "处理", "保存"]:
    recent.append(event)

print(list(recent))  # ['读取', '处理', '保存']
```
