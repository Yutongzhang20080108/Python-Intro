# 变量和基础数据结构

## 变量与赋值

先看一条简单的赋值语句。

```python
x = 5
```

Python 先对右边的表达式求值，再把左边的名字 `x` 绑定到得到的整数对象。CPython 会复用 `5` 这样的小整数对象，因此这条赋值语句可以直接引用已有对象。

在 CPython 的常规构建中，对象头包含引用计数和指向类型对象的指针。整数对象还保存用于表示整数值的数据。

## GIL (Global Interpreter Lock)

GIL 是全局解释器锁。在启用 GIL 的 CPython 中，同一个解释器一次只允许一个线程执行 Python 字节码。其他线程可以轮流执行，解释器也可以在阻塞 I/O 期间释放 GIL，让其他线程继续运行。

GIL 会保护解释器内部的共享状态，包括引用计数的更新。CPython 主要通过引用计数管理对象的生命周期。普通对象的引用计数降到 `0` 时会被释放，循环垃圾回收器负责补充处理已不可达的循环引用。

从 Python 3.13 起，CPython 提供了可以禁用 GIL 的自由线程构建。

## 基础数据结构

### 整数

Python 的内置整数类型是 `int`。它支持任意精度，能表示多大的整数受可用内存等资源限制。这一点和 Haskell 的 `Integer` 类似。

### 浮点数

Python 的内置浮点数类型是 `float`。CPython 使用 C 的 `double` 表示它，在常见平台上是 64 位双精度浮点数。许多十进制小数只能用二进制浮点数近似表示，例如 `0.1 + 0.2` 在常见平台上会得到 `0.30000000000000004`。

使用 NumPy 数组或 PyTorch 张量时，可以通过 `dtype` 选择数据类型，例如 `float32` 或 `float64`。

### String 和 Char

Python 用 `str` 表示 Unicode 字符串。通过索引取出的结果也是 `str`，长度为 `1`。例如，`"你好"[0]` 得到 `"你"`。

### Bool

布尔类型 `bool` 只有 `True` 和 `False` 两个值。`bool` 是 `int` 的子类，因此 `True == 1` 和 `False == 0` 都成立。`1` 和 `0` 本身是整数，`bool(1)` 和 `bool(0)` 分别把它们转换成 `True` 和 `False`。

### Set

`set`（集合）是可变、无序的容器，存放互不相等的可哈希元素。CPython 用哈希表实现集合，检查、添加、删除单个元素的平均时间复杂度都是 `O(1)`。

空集合用 `set()` 创建。下面是三种创建非空集合的写法。

```python
set_a = {1, 2, 3, 4}  # 集合字面量
set_b = set([1, 2, 2])  # 从可迭代对象创建，重复元素只保留一次
set_c = {x**2 for x in range(5)}  # 集合推导式
```

常用操作包括添加、删除和检查成员。

```python
s = {1, 2, 3}

s.add(4)  # 添加一个元素
s.update([4, 5])  # 从可迭代对象添加元素

s.remove(1)  # 删除 1，如果它不存在就抛出 KeyError
s.discard(1)  # 如果 1 存在就删除，不存在时也能继续执行

print(2 in s)  # True
```

两个集合 `a` 和 `b` 可以做并集 `a | b`、交集 `a & b`、差集 `a - b` 和对称差集 `a ^ b`。

### Dict

`dict`（字典）存储键值对，并保留键的插入顺序。键必须可哈希，值可以是任意 Python 对象。CPython 用哈希表实现字典，按键查找的平均时间复杂度是 `O(1)`。

字典可以用字面量或字典推导式创建，空字典写作 `{}`。

```python
dict_a = {"a": 1, "b": 2}
dict_b = {x: x**2 for x in range(5)}
```

下面的例子演示如何查找、添加、更新和删除键值对。

```python
d = {"name": "Alice", "age": 25}

print(d["name"])  # Alice
print(d.get("city", "未知"))  # 未知，键不存在时返回默认值
print("name" in d)  # True，in 检查的是键

d["city"] = "Beijing"  # 新增一个键值对
d.update({"age": 26, "job": "dev"})  # 更新 age，新增 job

del d["job"]  # 删除键值对，键不存在时会抛出 KeyError
age = d.pop("age")  # 删除对应的键值对，并返回它的值
print(age)  # 26

d["name"] = "Denny"  # 改变一个key对应的值
```

### List

`list`（列表）是有序、可变的序列，允许重复元素，也可以混合存放不同类型的对象。列表适合保存一组会增减或修改的数据，比如一组成绩。

可以用方括号、`list()` 或列表推导式创建列表。

```python
empty = []
nums = [10, 20, 20]
from_range = list(range(3))  # [0, 1, 2]
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
```

索引从 `0` 开始，`-1` 表示最后一个元素。切片 `nums[start:stop]` 从 `start` 开始，取到 `stop` 之前。

```python
nums = [10, 20, 30]

print(nums[0])  # 10
print(nums[-1])  # 30
print(nums[1:3])  # [20, 30]

nums[1] = 25  # 替换索引 1 处的值
nums.append(40)  # 在末尾添加一个元素
nums.extend([50, 60])  # 在末尾逐个添加可迭代对象中的元素
nums.insert(1, 15)  # 在索引 1 处插入 15
nums.remove(30)  # 删除第一个等于 30 的元素，找不到时抛出 ValueError
last = nums.pop()  # 删除并返回最后一个元素，空列表会抛出 IndexError

print(last)  # 60
print(nums)  # [10, 15, 25, 40, 50]
print(25 in nums)  # True
```

`nums.sort()` 直接对原列表排序，返回 `None`。`sorted(nums)` 返回一个排好序的新列表。

CPython 的列表用动态数组存放元素的引用。按索引访问是 `O(1)`，在末尾追加一个元素的均摊时间是 `O(1)`。在开头或中间插入、删除可能需要移动后续元素，最坏是 `O(n)`。查找一个元素是`O(n)`。

### tuple

`tuple`（元组）是有序、不可变的序列，允许重复元素，也可以存放不同类型的对象。元组常用来表示各个位置含义固定的一组数据，比如二维坐标 `(x, y)`。

创建只有一个元素的元组时，记得在元素后加逗号。

```python
empty = ()
single = (3,)  # 单元素元组
point = (3, 4)
from_list = tuple([3, 4])  # (3, 4)
```

元组支持索引、切片、`in` 和 `len()`。还可以通过解包，一次把多个元素分别赋给变量。

```python
point = (3, 4)

print(point[0])  # 3
print(point[:1])  # (3,)
print(4 in point)  # True
print(len(point))  # 2

x, y = point  # 解包
print(x, y)  # 3 4
```

元组创建后，各个位置引用的对象固定。例如，给 `point[0]` 赋值会抛出 `TypeError`。如果某个元素本身是列表，仍然可以修改这个列表的内容。

```python
record = ("小明", [90, 85])
record[1].append(95)
print(record)  # ('小明', [90, 85, 95])
```

当所有元素都可哈希时，元组可以作为字典的键或集合的元素，例如坐标 `(3, 4)`。
